# Founder

Verified facts about the founder. The AI may state only facts listed here **with a source**.
It must never invent biography, location, customers, projects, revenue, conversations or stories.

How to add a fact:

- One fact per bullet, ending with `(source: where this is confirmed)`.
  Example: `- Has led software teams since 2015. (source: owner statement, 2026-10-14)`
- A bullet without `(source: ...)` is imported as **unverified** and is never used.
- After editing, run `uv run python manage.py sync_knowledge`.
