How to add a fact:

- One fact per bullet, ending with `(source: where this is confirmed)`.
  Example: `- Builds web and mobile products for startups. (source: company website, 2026-10-14)`
- A bullet without `(source: ...)` is imported as **unverified** and is never used.
- After editing, run `uv run python manage.py sync_knowledge`.
